# Flutter Toybox

Four Flutter apps built while learning the framework: three games and a
calculator. Each folder is a standalone project, so open the one you want, run
`flutter pub get` and then `flutter run`.

| Project                     | What it is                                                                                                  |
| :-------------------------- | :----------------------------------------------------------------------------------------------------------- |
| [tetris](tetris/)           | Arcade tetris on a ten by twenty field: SRS rotation with wall kicks, hold, a ghost piece, rising levels and a saved best score. |
| [checkers](checkers/)       | International draughts on ten by ten, with compulsory maximum capture, flying kings and a computer opponent at three levels. |
| [tic-tac-toe](tic-tac-toe/) | Tic-tac-toe with nicknames, a match played to three rounds, and a computer opponent at three levels.          |
| [calculator](calculator/)   | A four-function calculator.                                                                                   |

Every project carries its own README with a screenshot of each screen.
